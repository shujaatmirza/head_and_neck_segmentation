02 / 13 01
Motivation

The Problem

Radiation therapy for head & neck cancer requires precise delineation of organs-at-risk. Manual segmentation is slow, costly, and inconsistent.

Challenge 1
Class Imbalance
OARs occupy <5% of the CT volume. Naive models predict only background.
Challenge 2
Memory Limits
A single 3D volume + UNet can exceed 30 GB, forcing batch size = 1.
Challenge 3
Limited Data
Only 33 training volumes — high risk of overfitting.

Discussion

Key Insights

1. Model Depth Matters Most

Deeper UNet: 0.755. Shallow networks produce zero Dice for small structures like chiasm and optic nerves.

2. Combine Loss Functions

Dice-CE improves over Dice alone by +3.6%. CE covers large structures, Dice focuses on small organs.

3. Augment After Warm-up

Delayed elastic deformation: +4.4%. The model learns basic features before seeing augmented data.

4. Batch Size & LR Interact

Linear LR scaling fails for variable-sized 3D volumes. Moderate batch sizes (2–4) without scaling work best.

Limitations & Future Work

What’s Next?

Limitations

  • Fixed train/test split, no cross-validation
  • Only Dice metric — no Hausdorff distance
  • Small test set (5 patients)
  • No ensemble methods explored

Future Directions

  • K-fold cross-validation with confidence intervals
  • Hausdorff distance & surface DSC metrics
  • Attention mechanisms (Swin UNETR)
  • nnU-Net self-configuring pipeline
